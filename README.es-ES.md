# Spectacles Lens Studio Samples

Una colección de proyectos de muestra autónomos para [Lens Studio](https://developers.snap.com/lens-studio/home), dirigidos a las gafas de RA Spectacles. Cada proyecto demuestra características y técnicas específicas con dependencias mínimas.

## Proyectos

**1. [Vector Fields](Vector-Fields/)** - Visualización interactiva de campos vectoriales con ajustes preestablecidos de campos analíticos (expansión, contracción, circulación, vórtice, ondas) y visualización de dipolo magnético.

<img src="assets/vector-fields/magnetic-field-demo.gif" width="500">

**2. [Color Spaces](Color-Spaces/)** - Visualización interactiva de varios espacios de color. También demuestra la manipulación de mallas procedimentales en Lens Studio.

<img src="assets/color-spaces/demo.gif" width="200">

**3. [Eyedropper](Eyedropper/)** - Una herramienta de selector de color que toma muestras de colores del mundo real.

<img src="assets/eyedropper/demo.gif" width="200">

---

## Primeros Pasos

1. Descarga e instala [Lens Studio](https://developers.snap.com/lens-studio/home)
2. Clona este repositorio
3. Abre cualquier archivo `.esproj` de un proyecto en Lens Studio

## Agregar Nuevos Proyectos

Cada proyecto de muestra sigue esta estructura:

```
ProjectName/
├── ProjectName.esproj
└── Assets/
    ├── Scripts/
    ├── Materials/
    ├── Images/
    ├── Meshes/
    └── Prefabs/
```
